# Terrastruct

> Terrastruct builds diagramming tools crafted to visualize software architecture. Its flagship is D2, a modern, open-source (MPL-2.0) diagram scripting language that turns text into diagrams (SVG, PNG, PDF, PPTX, GIF, and ASCII). Terrastruct also builds D2 Studio (a hosted drag-and-drop + text IDE) and TALA (a proprietary layout engine designed for software architecture diagrams). There is no public REST API; D2 is consumed as a CLI, a Go library (d2lib / d2oracle), and a WASM-backed JavaScript library (D2.js).

## Products

- [D2 language](https://d2lang.com): Open-source text-to-diagram scripting language. Docs at d2lang.com.
- [D2 Studio](https://terrastruct.com/d2-studio): Hosted diagramming IDE (app at https://app.terrastruct.com/).
- [TALA](https://terrastruct.com/tala): Layout engine designed specifically for software architecture diagrams.
- [Plugins](https://terrastruct.com/plugins): Official VSCode, Vim, and Obsidian integrations.

## Developer tooling

- [D2 CLI](https://d2lang.com): `d2 input.d2 output.svg`; `--watch` for live preview; `d2 fmt` to format. Install: `brew install d2` or `curl -fsSL https://d2lang.com/install.sh | sh -s --`.
- [D2 as a Go library](https://github.com/terrastruct/d2): `go install oss.terrastruct.com/d2@latest`; d2oracle for programmatic diagram generation.
- [D2.js (npm @terrastruct/d2)](https://www.npmjs.com/package/@terrastruct/d2): WASM build of D2 for the browser/Node.
- [D2 Playground](https://play.d2lang.com): Online D2 runner.
